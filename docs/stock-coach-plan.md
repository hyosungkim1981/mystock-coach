# 국내주식 포트폴리오 코칭 봇 기획

## 목표

국내주식 보유 현황을 MTS 화면 캡처 이미지에서 읽어오고, 종목별 평단가, 현재가, 수익률, 비중을 계산해 매수/보유/매도 액션 단계를 대시보드로 보여준다.

이 도구는 투자 결정을 대신하지 않고, 보유 종목을 점검하기 위한 코칭 보조 도구로 설계한다.

## 1차 MVP 범위

- MTS 캡처 이미지 업로드
- 브라우저 OCR 시도
- OCR 결과 텍스트 보정 입력
- 종목명, 종목코드, 수량, 평단가, 현재가, 수익률, 비중 파싱
- 파싱된 보유 종목 직접 수정
- 종목별 액션 점수 산출
- 적극매수, 분할매수 1단계, 분할매수 2단계, 보유, 분할매도 1단계, 분할매도 2단계, 적극매도 단계 표시
- 포트폴리오 요약 대시보드

## 입력 데이터

MTS 이미지 OCR에서 우선 인식할 항목은 다음과 같다.

- 종목명
- 종목코드
- 수량
- 평단가
- 현재가 또는 평가단가
- 수익률
- 비중

OCR이 틀릴 수 있으므로 결과 텍스트와 표 데이터를 모두 사용자가 수정할 수 있어야 한다.

## 액션 점수 체계

액션 점수는 0-100%로 표현한다. 100에 가까울수록 매수 쪽, 0에 가까울수록 매도 쪽 신호로 본다.

| 점수 범위 | 액션 단계 | 의미 |
|---:|---|---|
| 85-100 | 적극매수 | 모멘텀, 수익률, 리스크가 모두 우호적 |
| 72-84 | 분할매수 2단계 | 매수 신호가 강하지만 단계적으로 접근 |
| 60-71 | 분할매수 1단계 | 관심 매수 구간, 소액/관찰 중심 |
| 45-59 | 보유 | 추가 매수/매도보다 관찰 우선 |
| 33-44 | 분할매도 1단계 | 리스크 일부 축소 검토 |
| 20-32 | 분할매도 2단계 | 비중 축소 필요성이 큼 |
| 0-19 | 적극매도 | 손실/리스크/뉴스 악화가 큰 상태 |

## 점수 계산 초안

1차 MVP는 MTS 보유 정보만으로 계산하고, 뉴스와 회사 정보는 수동 점수 또는 후속 API 연결 대상으로 둔다.

- 가격 모멘텀: 수익률 기반
- 뉴스 모멘텀: 기본 0점, 사용자가 종목별로 -100부터 100까지 조정
- 비중 리스크: 포트폴리오 내 비중이 높을수록 추가매수 점수를 낮춤
- 손익 리스크: 큰 손실 또는 과도한 급등은 보수적으로 반영
- 포지션 품질: 적정 수익률과 관리 가능한 비중을 우호적으로 평가

## 2026-06-27 MTS 샘플 이미지 디버깅

제공된 MTS 캡처는 `종목명 / 수익률 / 평가손익 / 평가금액` 화면이다. 기존 MVP 파서는 `종목명 / 종목코드 / 수량 / 평단가 / 현재가 / 수익률 / 비중`이 한 줄에 있는 텍스트를 우선 지원했기 때문에 이 화면을 온전히 읽지 못했다.

수정 내용:

- `평가손익 / 평가금액` 기반 보유 화면 파서 추가
- OCR 결과가 행 단위로 나오거나 컬럼 단위로 나와도 읽을 수 있게 처리
- 평가금액 합계 기준으로 종목별 비중 자동 계산
- 표에 평가금액 컬럼 추가
- 수량/평단가가 이미지에 없는 경우 사용자 메시지로 안내
- `file://`로 열었을 때 OCR 엔진 제한 가능성 안내

제한 사항:

- 제공된 이미지에는 수량과 평단가가 보이지 않으므로, 이 화면만으로 평단가를 계산할 수 없다.
- 평단가까지 자동 입력하려면 MTS에서 수량/평균단가 컬럼이 보이는 화면 캡처가 필요하다.
- 이미지 OCR은 브라우저 보안 정책 때문에 파일을 직접 여는 방식보다 로컬 서버 주소로 여는 방식이 안정적이다.

- 현재가가 있는 종목은 추천 매수가, 2차 매수가, 추천 매도가, 일부 매도 기준, 손절 기준을 계산

- 아직 실시간 회사정보, 재무제표, 뉴스 API가 연결되어 있지 않으므로 성장성 점수는 사용자가 직접 조정한다.
- 실제 기업 성장성 자동 판단은 DART, 뉴스, 재무 데이터 연동 후 고도화한다.
- 매수/매도 추천가는 현재가 기반의 참고 기준이며 투자 판단을 대체하지 않는다.

## 2026-06-29 카카오톡 연동 검토

목표:

- 사용자가 카카오톡에서 MTS 잔고 이미지를 보내면 종목별 코칭 대시보드를 확인할 수 있게 한다.
- 가능하면 오픈채팅방 안에서 자연스럽게 결과를 공유한다.

공식 API 검토 결과:

- 카카오 디벨로퍼스 웹훅은 계정 연결 해제, 계정 상태 변경, 카카오톡 공유 전송 성공, 카카오톡 채널 추가/차단 같은 이벤트 중심이다.
- 카카오톡 공유는 사용자가 서비스 화면에서 공유할 내용을 선택한 뒤 카카오톡 친구 또는 채팅방으로 보내는 기능이다.
- 카카오톡 메시지 API는 같은 서비스 사용자 또는 친구에게 메시지를 보내는 목적이며, 서비스가 일반 오픈채팅방 메시지와 이미지를 직접 수신하는 공식 입력 채널로 보기 어렵다.
- 카카오톡 채널 챗봇의 스킬 서버는 봇 시스템에서 HTTP POST 요청을 받아 응답하는 구조로, 오픈채팅방이 아니라 카카오톡 채널 기반으로 검토해야 한다.

권장 방향:

1. 1단계는 웹 업로드 중심으로 유지한다.
   - 오픈채팅방에는 `대시보드 만들기` 링크를 고정 공지 또는 버튼으로 제공한다.
   - 사용자는 링크를 열어 MTS 이미지를 업로드한다.
   - OCR, 점수 계산, 대시보드 생성은 현재 웹앱 또는 서버에서 처리한다.
   - 결과 화면에 `카카오톡 공유` 버튼을 추가해 오픈채팅방에 결과 링크를 다시 공유한다.

2. 2단계는 카카오톡 채널 챗봇을 별도 검토한다.
   - 카카오톡 채널을 만들고 챗봇 관리자센터 스킬 서버를 연결한다.
   - 사용자가 채널 챗봇에 이미지를 보내면 서버가 이미지 URL 또는 입력값을 받아 OCR 작업을 큐에 넣는다.
   - 챗봇 응답은 즉시 처리 가능한 요약 또는 대시보드 링크로 반환한다.
   - 스킬 응답 시간 제한이 있으므로 OCR과 뉴스 분석은 백그라운드 작업으로 분리하는 설계가 필요하다.

3. 일반 카카오톡 PC 자동화 또는 화면 스크래핑은 제외한다.
   - 공식 API가 아니므로 안정성, 약관, 보안, 개인정보 리스크가 크다.
   - 잔고 이미지에는 계좌/자산 정보가 포함되므로 비공식 자동화는 서비스화하지 않는다.

필요한 서버 API 초안:

- `POST /api/v1/portfolio-sessions`: 이미지 업로드 또는 이미지 URL을 받아 분석 작업 생성
- `GET /api/v1/portfolio-sessions/{id}`: 분석 상태와 결과 조회
- `POST /api/v1/portfolio-sessions/{id}/share-links`: 카톡 공유용 만료 링크 생성
- `DELETE /api/v1/portfolio-sessions/{id}`: 사용자가 업로드 이미지와 분석 결과 삭제

보안 원칙:

- 업로드 이미지는 파일 형식, 확장자, 용량을 검증한다.
- 분석 결과 링크는 추측 불가능한 토큰과 만료 시간을 둔다.
- 잔고 이미지 원본은 기본 24시간 이내 자동 삭제한다.
- 카카오 앱 키, OCR API 키, 뉴스 API 키는 환경 변수로 관리한다.
- 로그에는 종목명 정도만 남기고 계좌번호, 이름, 이미지 URL, 원본 OCR 전문은 남기지 않는다.

- 공유 메시지에는 `점검 종목 수`, `평균 액션`, `가중 수익률`, `대시보드 링크`만 포함한다.
- 공유 링크는 URL의 query/hash를 제거해 OCR 전문이나 화면 상태가 의도치 않게 공유되지 않도록 했다.

## 보안 및 개인정보 원칙

- 업로드 이미지는 기본적으로 브라우저 안에서 처리한다.

- API 키는 코드에 넣지 않고 환경 변수 또는 설정 저장소를 사용한다.
